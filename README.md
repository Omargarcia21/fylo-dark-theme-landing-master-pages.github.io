# Solución al Desafío de Frontend Mentor: Bento Grid con Tema Oscuro

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Bento Grid** de Frontend Mentor. El objetivo era crear una página estática con un diseño responsivo utilizando CSS Flexbox y CSS Grid.

**Desafío de Frontend Mentor:** [Bento Grid](https://www.frontendmentor.io/challenges/bento-grid-RMydElrlOj)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/fylo-dark-theme-landing-master-pages.github.io/)

## Descripción del Proyecto

Este proyecto es una página estática que presenta un diseño moderno y responsivo utilizando **CSS Flexbox** y **CSS Grid**. La página incluye:

- Una sección principal con un diseño de cuadrícula (Bento Grid) que muestra información en bloques organizados.

El diseño es completamente responsivo, adaptándose a diferentes tamaños de pantalla, desde dispositivos móviles hasta desktop.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS, JavaScript.
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
